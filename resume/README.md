# 개인 이력서 템플릿 사용법

index.html을 브라우저에서 열면 이력서를 볼 수 있습니다. 설치할 프로그램이나 빌드 과정은 없습니다. 디자인은 style.css에 분리했습니다.

## 수정 순서

1. index.html의 활동명과 title을 바꾸세요. 실명·학번·생년월일·주소·연락처·얼굴 사진·출신 학교명은 넣지 마세요.
2. GitHub 링크의 YOUR_GITHUB_ID를 본인 ID로 바꾸세요.
3. 예시 실적을 사실에 맞게 바꾸세요. 최소 4건, 중·고등학교 시절 실적 최소 1건이 필요합니다. 시기는 YYYY.MM, 최신순으로 정렬하세요.
4. 2026-2 실제 수강 과목을 모두 입력하고 전공/교양 구분을 확인하세요.
5. 진행한 주차의 div를 HTML 주석에 있는 a 예시처럼 바꾸고 실제 실습 URL을 넣으세요. 진행하지 않은 주차만 예정으로 남기세요. completed 클래스는 녹색, planned 클래스는 회색입니다.
6. footer의 날짜와 datetime을 배포 저장소의 마지막 커밋 날짜로 맞추세요. 실제 진행 상황을 반영한 뒤 노란색 템플릿 안내와 예시 문구를 삭제하세요.
7. 본인의 smu.ai.kr 사이트에 index.html과 style.css를 같은 폴더에 올리세요. 현재 템플릿은 배포되지 않았습니다.
8. 배포 페이지에서 검수하고 images/에 개인정보를 가린 캡처를 저장하세요. REPORT.md의 미검수를 Pass 또는 Fail (기준 번호)로 바꾸고 실제 이미지 링크와 완성도를 입력하세요.
9. 수정한 소스와 REPORT.md, 증빙 images/를 ZIP 최상위에 넣고 제출 파일명을 Mid_학번_이름.zip으로 바꾸세요. 학번과 이름은 제출 파일명에만 사용하고 사이트·리포트에는 넣지 마세요.

## 구조

- index.html: header → main의 실적 / 수강 과목 / 주차별 링크 section → footer
- style.css: 외부 스타일시트, 반응형 배치, 완료/예정 색 구분
- REPORT.md: 검수 및 분석 작성용 초안
- images/: 검수 캡처 저장 위치

현재 GitHub URL은 자리표시자이며 실습 링크는 입력 전입니다. W3C 검사와 실제 배포 검수는 수행하지 않았습니다. 로컬 구조 확인을 과제 Pass로 기록하지 않았습니다.
